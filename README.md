### 2. 如何使用本模板
#### 2.1 下载本模板
登录github克隆本模板，解压到本地文件夹，然后使用vscode打开文件夹，即可使用本模板进行论文写作。
也可以使用git命令下载本模板，命令如下：
```
git clone https://github.com/447662/gdut-latex-.git
```

#### 2.2 修改个人信息
1. 在1_1_课程论文封皮.doc文件中，修改个人信息，包括姓名、学号、学院、专业、指导教师等。
2. 将修改好的文件另存为1_1_课程论文封皮.pdf文件，替换本模板中的1_1_课程论文封皮.pdf文件。

#### 2.3 修改论文内容
1. 在1.tex文件中用latex指令书写论文内容，包括摘要、关键词、正文、参考文献等。
2. 运行1.tex文件，即可生成论文。

#### 2.4 修改论文参考文献
1. 在cankaowenxian.bib文件中，添加参考文献条目，包括作者、标题、出版社、出版日期等。
2. 在1.tex文件中，使用\cite{}指令引用参考文献，例如\cite{zhang2019deep}

#### 2.5 修改论文格式
1. 在1.tex文件中用latex指令修改论文格式，包括字体、字号、行间距等。

2. 运行1.tex文件，即可生成论文。

### 备注
由于广工于2026年修复了毕设可以用latex的bug——新增了格式检查这一项，不查就不能查重和AIGC，而格式检查只支持Word，不支持pdf。
所以建议大家搭配latex转Word的AIskills使用。（市面上的latex转Word软件基本上不支持毕设这么复杂的项目）
